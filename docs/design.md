# V3 design

V3 keeps nine explicit skills. Onboarding, tutorial, architecture, trace, deep-dive, change, and verify are Codex-guided source workflows because boundaries, intent, runtime behavior, logical relationships, and claim meaning require selective semantic inspection. Hotspots and coupling retain one narrow deterministic helper because bounded history parsing, rename handling, bulk filtering, LOC counting, and deterministic ranking materially reduce context and improve reproducibility.

Temporal history is an observation. Static, logical/domain, and test coupling remain targeted semantic investigation; temporal coupling is never automatically a defect. The helper has explicit Git and Code Maat branches, no provider registry, generic evidence ontology, cache, ecosystem discovery, architecture/call/impact analyzer, or recommendation layer. Provenance is result-level because candidates are one bounded result, not an independent evidence store. Observations remain separate from conclusions.
