# Codebase conversational tutorial
Read [analysis basics](../../shared/references/analysis-basics.md). Use the requested audience, focus, and format, otherwise assume a competent developer and chat output. Reconnoiter cheaply, curate genuine core concepts, map each to verified source/symbols/configuration/tests, establish relationships, and order purpose/foundations before mechanics/dependants. Include useful excerpts, edge behavior, reading guidance, and diagrams only when helpful; verify paths, links, symbols, and edges. Stop when distinctive mechanisms and dependencies are teachable and further detail is scaffolding. Deliver the progressive tutorial and explicit limitations. Do not persist artifacts unless requested.

When architecture, execution flow, component relationships, or state transitions
would be easier to teach visually, read
[diagramming](../../shared/references/diagramming.md) and provide the verified
concepts, components, actors, relationships, execution order, boundaries,
states, and examples relevant to the current teaching step.
